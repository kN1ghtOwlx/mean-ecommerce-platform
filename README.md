# MERN E-Commerce Platform

## Features

- User Authentication
- Product Management
- Category Management
- Protected Routes
- Cookie Authentication
- AI Product Assistant
- Gemini API Integration
- Responsive React Frontend
- Express REST API
- MongoDB Database

## Technology Stack

### Frontend

- React
- Vite
- React Router
- Axios
- CSS

### Backend

- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- Cookie Parser
- Gemini API

## Installation

### Backend

```bash
npm install

npm run dev
```

### Frontend

```bash
cd client

npm install

npm run dev
```
